## Overview

**Vantage** is an elite creator intelligence suite designed to eliminate guesswork in video production and social storytelling. Built with a dark OLED aesthetic, tactile glassmorphism, and bold typographic hierarchy, Vantage helps creators reverse-engineer viral momentum across **YouTube Long-form, Shorts, Instagram Reels, TikTok, X Threads, and LinkedIn**.

---

## Features

- **Massive Bold Typography & Visual Hierarchy**: Built with **Clash Display**, **Plus Jakarta Sans**, and **JetBrains Mono** for maximum scannability and contrast.
- **Tactile Glowing Virality Badges**: Multi-tier neon score badges (Emerald `#00F59B` for 90+ Breakout Viral Hits, Cyber Amber `#FFB454` for 70-89 High Reach, Electric Violet `#8B7CF6` for Calibrated Baseline).
- **Structured Bento-Box Grid**: Asymmetric 4-column layout featuring an interactive flagship spotlight card with a simulated 60s retention wave graph.
- **Floating Glass Command Search**: Real-time filtering with instant query highlighting across hooks, platforms, and psychological tags (`⌘K` / `Ctrl+K`).
- **Interactive AI Virality Scorer**: Live algorithmic simulator computing Curiosity Gap, Stakes/Conflict, and Algorithmic Velocity with 1-click high-converting AI rewrite suggestions.
- **Deep-Dive Retention Drawer**: Slide-over inspector providing audience drop-off curves, psychological trigger indexes, and recommended thumbnail pairings.
- **Batch Scorer & Competitor Scanner**: Rapidly import competitor video links or multiple hook drafts at once.
- **Lucide Iconography**: 100% vector Lucide icons for an ultra-clean, emoji-free professional UI.
- **1-Click Bookmark & Copy**: Instant clipboard copying with smooth toast feedback.

## Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| <kbd>⌘</kbd> + <kbd>K</kbd> / <kbd>Ctrl</kbd> + <kbd>K</kbd> | Focus global command search bar |
| <kbd>N</kbd> | Open AI Virality Scorer & Hook Calibrator modal |
| <kbd>Esc</kbd> | Close active modal or detail slide-over drawer |

## Tech Stack

- **Core**: Semantic HTML5, Vanilla JavaScript (ES6+)
- **Styling**: Vanilla CSS (CSS Custom Properties, Glassmorphism `backdrop-filter`, Custom 1px Gradients, Micro-animations)
- **Typography**: Clash Display, Plus Jakarta Sans, JetBrains Mono, Space Grotesk
- **Iconography**: [Lucide Icons](https://lucide.dev)
- **Deployment**: Automated GitHub Pages via GitHub Actions workflow

## Getting Started Locally

No complex dependencies or build steps required. Clone and open:

```bash
# Clone the repository
git clone https://github.com/adm04/Virality.git

# Navigate to the folder
cd Virality

# Option 1: Open directly in your browser
start index.html

# Option 2: Serve locally with any static server
npx serve .
```
