# Vantage — Content Idea Library & Virality Scorer

An ultra-modern, high-converting SaaS dashboard engineered for top-tier creators (YouTube Long-form, Shorts, Instagram Reels, TikTok, X Threads, and LinkedIn).

![Vantage Dashboard Banner](https://images.unsplash.com/photo-1618005182384-a83a8bd57fbe?auto=format&fit=crop&w=1400&q=80)

## 🌟 Key Features

- **Massive Typography & Flawless Hierarchy**: Built with **Clash Display**, **Plus Jakarta Sans**, and **JetBrains Mono**.
- **Tactile Glowing Virality Badges**: Multi-tiered neon badges (Emerald `#00F59B` for 90+ Viral Tier, Cyber Amber `#FFB454` for 70-89, Amethyst `#8B7CF6`).
- **Structured Bento-Box Grid & Masonry**: Asymmetric layout featuring a flagship spotlight hero card with a live retention wave graph and sparkline indicator.
- **Floating Command Bar & Instant Filter**: Real-time filtering across hook text, platform names, tags, and psychological triggers with query keyword highlighting (`⌘K` / `Ctrl+K`).
- **Interactive AI Virality Scorer**: Live hook scoring engine analyzing Curiosity Gap, Stakes / Conflict, and Algorithmic Velocity with 1-click AI rewrite suggestions.
- **Card Deep-Dive Slide-Over Drawer**: Inspect projected 60s retention curve charts, psychological lever ratings, and recommended thumbnail pairings.
- **Batch Scorer & Competitor Scanner**: Process competitor video links or multiple hook drafts at once.
- **1-Click Bookmark & Copy**: Instant clipboard copying and bookmark saving with animated toast feedback.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Using standard HTTP server
npx serve .
```

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS**: Clean semantic markup, modern CSS custom properties, frosted glassmorphism (`backdrop-filter: blur(24px)`), and 1px translucent gradient borders.
- **Vanilla JavaScript (ES6+)**: Zero external JS dependencies, lightweight client-side state management, real-time scoring heuristic simulation, and keyboard navigation.
